# GitHub

Acest proiect e legat de GitHub (remote `origin`, contul octobotul23).
- După fiecare modificare terminată, fă un commit cu un mesaj scurt și clar, în engleză, care spune ce s-a schimbat (ex. "Add driver route export to CSV").
- Nu pune niciodată în git parole, chei API, `.env`, baze de date sau date de clienți.
- La finalul fiecărui răspuns, un hook face automat `git add -A`, commit (dacă a rămas ceva nesalvat) și `git push`.
